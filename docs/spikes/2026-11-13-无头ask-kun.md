# 实测：没有会话身份的程序用 ask-kun 发卡、取回答

日期 2026-11-13。为实施计划里「车间的程序发卡问 Kun，答了再接着走」先试一次；之前没人这样无头用过。

## 结论

能用。车间的守护进程照这个做：

1. 发卡：`ask-kun ask --no-wait --from 车间 --subject … --decision … --choice k=… --effect k=… --recommend k --reason … --kind reversible|approval`，stdout 打印编号（如 `Q1836`），车间记进日志。
2. 取回答：每个 tick 跑一次 `ask-kun wait Qn --timeout 0`。退出码 0：stdout 是 Kun 点的按钮文字（`--answer-format key` 可改成返回选项 key）；退出码 3：还没答，问题保留，下次再查。
3. 不带 `--default` 时问题没有截止时间，一直等到 Kun 答；`deadline` 字段只在有默认答案时起作用（`ask-kun` 第 495–540 行）。

## 要注意的

- 程序调用的入口是 `~/workspace/runtime/worktrees/oh-my-assistant/workbench/workbench/agent-bin/ask-kun`（`uv run` 包装，经接线台服务 127.0.0.1:4790 发出）。launchd 下 PATH 很短，要带上 `/opt/homebrew/bin`（uv 在那里）。
- 发完先打印「已排队」，约 23 秒后工作台以卡片发出（`transport: card`）。
- Kun 点按钮时由工作台把答案写进状态文件（`answered_via: card`），和有没有进程在等无关：这次 11:52:36 记下答案，等着的进程 11:52:52 下一次轮询才拿到；事后再 `wait --timeout 0` 拿到同一个答案。所以车间不用常驻等待。
- 记录里 `session`、`pane` 为空，`from` 是「车间」；没有会话可以转回，答案只留在状态文件里，靠车间来取。

## 过程和原样输出

模拟 launchd 的空环境（没有 `CLAUDE_CODE_SESSION_ID`、`ORCA_*`），在非 git 目录里发：

```
$ env -i HOME=$HOME PATH=/usr/bin:/bin:/usr/sbin:/sbin:/opt/homebrew/bin LANG=en_US.UTF-8 \
    …/agent-bin/ask-kun ask --no-wait --from 车间 \
    --subject "车间实测：无头发卡" --decision "测试卡：点任意一个按钮即可" \
    --context "车间开工实测：没有会话身份的程序能否发卡并取回你的回答。点哪个都算成功。" \
    --choice ok=收到 --choice later=换一个也行 \
    --effect ok=记为实测成功 --effect later=同样记为成功，只测回传 \
    --recommend ok --reason "只测回传，选哪个都不影响别的" --kind reversible
exit=0
Q1836
ask-kun: 已排队 Q1836，用 ask-kun wait Q1836 等回复
```

查发送状态（`ask-kun list` 里 Q1836 的几项）：

```
{'status': 'waiting', 'send_state': 'sent', 'transport': 'card', 'message_id': 'om_x100b605cdb9c98bcde0503f6e02060c', 'sent_at': '2026-11-13T11:51:39+08:00'}
```

同样的空环境里等：

```
$ … ask-kun wait Q1836 --timeout 0
Q1836 这段等待超时；问题保留，可用 ask-kun wait 接着等
exit=3
$ … ask-kun wait Q1836 --timeout 2h      # 11:51:50 开始
换一个也行
exit=0                                   # 11:52:52 结束
```

Kun 点完后状态文件里的记录（节选）：

```
'from': '车间', 'session': '', 'pane': '', 'status': 'answered', 'transport': 'card',
'answer': '换一个也行', 'answered_via': 'card', 'answered_at': '2026-11-13T11:52:36+08:00', 'choice': 'later'
```

事后再取一次：

```
$ … ask-kun wait Q1836 --timeout 0
换一个也行
exit=0
```
