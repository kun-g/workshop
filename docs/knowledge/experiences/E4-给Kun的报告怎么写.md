# E4 给 Kun 的报告怎么写

## 怎么做

顶部一行总数；每张卡片一句话理由、最多 3 条要点；链接放在名字或版本号上，不单列一排；按实例一行；没有的不显示，次要的折叠。agent 交的判断分两个字段：给人看的一句话、给校验的依据。上线前用真实数据渲染一版自己过一遍（S1）。

## 为什么

把写给程序的判断字段原样堆上页面，Kun 读不出重点。
