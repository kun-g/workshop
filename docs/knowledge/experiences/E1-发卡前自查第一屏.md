# E1 发卡前自查第一屏

## 怎么做

用线上那一版的渲染代码，套上这次的真实申请，看第一屏：
- 第一句说清这次要做什么、对服务有什么变化；
- 提交号、批次号、申请编号都在折叠区；
- 批了能做到的，不比要做的事宽。

有一条不过，就先拦下，记进问题记录，不发给 Kun。

## 为什么

Kun 只批或拒，卡写坏了他只能硬批或退回，成本都在他身上。11-15 第三张发版卡第一次这样做，他没再提意见。
