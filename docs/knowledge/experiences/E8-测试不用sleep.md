# E8 测试不用 sleep

## 怎么做

慢调用：让替身阻塞在测试控制的闸门上，跨进程用文件或管道。等状态：查条件加总超时的循环，或者假时钟。确实要等真实时间的（进程超时、强杀），超时设成测试能控制的小值，逐条写理由。

## 为什么

用 sleep 的测试又慢又依赖机器负载，断言也只能退化成「真等了 N 秒」。
