# 发卡前用线上渲染代码自查

- 类别：经验
- 出处：2026-11-15 gc#174 发版卡（exec-1794748637-901ad1）；复盘报告 `contexts/projects/workshop/reviews/20261116_B_负责会话6c36ee03.md`（workspace 仓库）

要发给 Kun 的卡，先用线上那一版的渲染代码套上这次的真实内容，渲染出来自己看第一屏：
- 看得懂吗：第一句说清这次要做什么、对服务有什么变化；
- 第一屏有没有提交号、批次号、申请编号（应该在折叠区）；
- 批了能做到的，是不是比要做的事宽。

有一条不过，就先拦下，不发给 Kun。11-15 第三张发版卡是第一次这样做，Kun 没再提意见。工具：`scripts/项目经理/render_gc_card.py`。
