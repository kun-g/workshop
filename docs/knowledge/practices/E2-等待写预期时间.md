# E2 等待写预期时间

- 一句话：后台等待写预期时间，到点没变化也叫醒；工具是 `scripts/pm/watch.py --by`。
- 写在：docs/项目经理.md
- 机制：`scripts/pm/watch.py --by`
- 状态：在用
- 批准：—
- 来源：[盯梢只认状态变化](../lessons/20261115-盯梢只认状态变化.md)

## 怎么做

放后台等待时写清在等什么、预计几点。叫醒条件三个：盯的活进了等你、卡住、完成或换了阶段；过了预期时间加宽限还没变化；到了最长时间。叫醒时附上预期和实际。

```sh
uv run python scripts/pm/watch.py --items 'grant-console:scheduled_release' \
  --expect '同步脚本 21:47 超时，批次应转卡住' --by 21:47
```

## 为什么

预期的事到点没发生、状态也不变时，只认状态变化的盯梢不会叫醒，Kun 会先发现。
