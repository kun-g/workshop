# E3 网络排障先查实际路径

## 怎么做

先回答四件事：哪个 context 或账号、哪个客户端、走哪个代理或路由、出口 IP。kubectl 看 `kubectl config view --minify --context <ctx> -o jsonpath='{.clusters[0].cluster.proxy-url}'`，再看 HTTPS_PROXY 这类变量。测的路径要和客户端实际走的一致；要 Kun 动手之前，先把本机能测的测完。

## 为什么

查错路径会一路查到无关的地方，还让 Kun 批卡、截图。
