# 授权中心给自己发版会丢结果

另外促成：无（根治在 gc#179）。

**结论：选执行方式时，问一句「执行它的进程会不会被这次执行换掉」。会的话，结果要能在新进程里补回来。**

ws#122 返工改成用 `argocd/sync_app` 代执行发版。可同步的对象就是授权中心自己，执行同步的 Pod 会被这次同步换掉，结果写不回去。于是每次给授权中心发版都会：
- 飞书弹「目标回调服务超时未响应」；
- 卡片不变（Kun：「点了两次了，卡片没变化」）；
- 执行记录永远停在「执行中」；
- 车间批次一直等授权。
