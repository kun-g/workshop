# 网络排障查错了路径

central-admin 连不上。项目经理顺着 NetBird 的 EKS 路由一路查到 sc2 和集群白名单，让 Kun 批了三张授权卡、截了五轮后台图。Kun：「你现在问我，我也没有头绪」。其实 central-admin-agent 走的是 srerelay 上的 socks5 代理；真正的原因是 kubectl 当前 context 是 gmp-asia-agent-public，命令没带 `--context central-admin-agent`，集群根本没断过。

查法：kubectl 看 `kubectl config view --minify --context <ctx> -o jsonpath='{.clusters[0].cluster.proxy-url}'`，再看 HTTPS_PROXY 这类代理变量；不要直接拿 nc 或 curl 测目标 IP。11-16 车间连 GitHub 失败时照这条做，先对比守护进程和终端各走哪条路，很快查清。
