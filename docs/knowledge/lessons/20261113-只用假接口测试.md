# 只用假接口测试，上线就误报

**结论：代码第一次调用某个外部接口，合并前要用真实身份对它调一次，贴出原样返回。**

gc#132 给 NetBird 令牌做每日检查。用哪个接口，是从接口文档里挑的 `GET /api/users/current`，从没拿服务账号的真令牌调过；40 个测试全用假的 NetBird 接口，`scripts/check.sh` 全过。上线后每日检查误报，开了 gc#145 去修，最后连做法一起改成按到期日计时（gc#170）。

一半责任在 issue：验收步骤只有 `scripts/check.sh` 加「上线后看日志」，没要求合并前对真实接口试一次，执行者照步骤做也算合格。当时在 Pod 里只读调这个接口只要一条命令。

后续：Kun 11-16 把它提成更根本的一条，见规范「交付前做端到端测试」。
