# 盯更新第一份周报被评为垃圾

Kun：「整个报告都是垃圾」。他点名的问题：写「约 47 个容器」，他只关心有几个实例；理由是 agent 写给校验程序的辩护长段，没有重点也没有排版；一排「发布说明原文」链接；「本项没有」「已等 0 天」这类空字段照样显示。

他认可的新版：顶部一行总数；每张卡片一句话理由、最多 3 条要点，版本号本身就是原文链接；每个实例一行配反馈按钮；没有的不显示，次要的折叠。根因是把判断字段原样堆上页面，复审也没拿真实数据看成品。agent 交的判断要把「给人看的一句话」和「给校验的依据」分成两个字段。
