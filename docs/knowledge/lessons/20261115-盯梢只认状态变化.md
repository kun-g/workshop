# 盯梢只认状态变化，漏了两次

**结论：后台等待都要写预期时间；到了预期时间，状态没变也要叫醒。**

- 16:00 grant-console 第一次整点发版准时开始了。盯梢只在做完、卡住、等你操作时叫醒，16:09 Kun 先问「1609了，你怎么没动静」。
- 21:47 同步脚本按预期超时。但新代码把这种情况改成每 5 分钟重查一次授权，活一直停在「定时」，没转「卡住」；盯梢只认「卡住」，22:11 Kun 先问「现在22:11了」。

两次都是预期的事到点没发生，或者发生了但状态没变，盯梢不知道。工具：`scripts/pm/watch.py --by`。
