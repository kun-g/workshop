# P2 适当负载持续运转

## 怎么做

三段看：供给（有没有活可派）、流动（时间耗在哪）、负载（前两段的结果）。指标、口径、目标见 workspace 的 `contexts/projects/workshop/metrics.md`。位置占用低时，先查供给和流动，不要先加执行者。

## 为什么

初期要快速迭代，每周收尾件数这类结果指标反馈太慢；要看的是车间既不长时间空着，也不长时间排满。
