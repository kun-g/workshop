# P2 适当负载持续运转

- 一句话：车间要在适当负载下持续运转：指标按供给、流动、负载三段看，按小时出数。
- 写在：docs/项目经理.md、docs/协调对话.md
- 机制：ws#157（待做）：`workshop metrics` 按小时出数
- 状态：在用

- 来源：[11-16 复盘定方向](../lessons/20261116-复盘定方向.md)

## 怎么做

三段看：供给（有没有活可派）、流动（时间耗在哪）、负载（前两段的结果）。指标、口径、目标见 workspace 的 `contexts/projects/workshop/metrics.md`。位置占用低时，先查供给和流动，不要先加执行者。

## 为什么

初期要快速迭代，每周收尾件数这类结果指标反馈太慢；要看的是车间既不长时间空着，也不长时间排满。
