# P1 车间自己运转

## 怎么做

项目经理每做一次手工干预，都记进问题记录；协调对话把同一类干预攒起来，做成车间的命令、检查或关口。取舍时，选能让下一次不用再干预的做法，而不是多记一条规矩。

## 为什么

车间的目标是自己运转，现阶段还离不开项目经理在旁兜底。手工干预的次数，就是车间还缺多少机制。
