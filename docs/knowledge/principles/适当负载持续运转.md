# 在适当负载下持续运转

- 类别：原则
- Kun 原话（2026-11-16）：「我希望整个系统是在适当的负载下去持续运转的，我们指标要考核这些东西」「我们现阶段是初期，要快速去迭代，我需要快速看到结果」「我理解是【供给】-【流动】->【负载】，然后考察这三个阶段，之后可以根据情况在这个框架下调整指标」

车间既不长时间空着，也不长时间排满。衡量用引导指标，按小时出数，分三段看：
- 供给：有没有活可派；
- 流动：时间耗在哪；
- 负载：是前两段的结果。

不拿每周收尾件数这类结果指标代替。位置占用低时，先查供给和流动，不要先加执行者。具体指标、口径和目标见 workspace 仓库的 `contexts/projects/workshop/metrics.md`。
