# S7 主检出只读

## 怎么做

`~/workspace/runtime/repos/workshop` 只做 fetch、log、show。改代码开 worktree，从 origin/main 拉分支。合并后急着上线跑 `workshop release-now`，再看 `workshop status` 和 `release.json`。
