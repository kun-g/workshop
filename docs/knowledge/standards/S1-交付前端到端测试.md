# S1 交付前端到端测试

## 怎么做

走 Kun 或下游真会碰到的那条路：真实身份调真实接口，真实数据渲染真实页面或卡片，原样贴出输出。合并前跑不了的（上线后才有的路径），上线后由验收 agent 先跑同一步骤，过了才收尾。只改文档的活不用做。

## 为什么

几篇教训是同一个毛病：交付前只在替身上测过。gc#132 用 40 个假接口测试全绿，上线就误报；发版卡没用真渲染器看过就发给 Kun；周报没用真实数据看过成品。原来那条「第一次调外部接口要用真身份试一次」并进这条。
