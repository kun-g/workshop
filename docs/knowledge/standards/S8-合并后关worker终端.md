# S8 合并后关 worker 终端

- 一句话：Orca worker 的 PR 合并后，同一步关掉它的终端。
- 写在：docs/项目经理.md、docs/协调对话.md
- 机制：只有文字
- 状态：在用
- 批准：待 Kun 过目
- 来源：[合并后 worker 终端还开着](../lessons/20261113-合并后worker终端还开着.md)

## 怎么做

PR 合并、确认不再有修改轮后，同一步 `orca terminal close`。worktree 和交接文件保留。要再派活，用 resume 接回原会话或另起。车间自己起的执行者会话由车间收尾时关。

## 为什么

开着的终端占 Kun 的注意力，也分不清哪些还在干活。
